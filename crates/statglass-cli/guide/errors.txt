Errors, freshness and gaps

Exit codes, each one next action:
  0    success: use the answer, after reading freshness and gaps
  1    bug (Defect, Unknown): rerun once; if it repeats, report it with statglass doctor --json
  2    fix the input (Usage, UnknownHost, UnknownMetric, BadRange); follow Did you mean
  4    retry in a few seconds (Busy)
  5    the data is not available, don't retry (HostOffline, HostDisabled, PeerTooOld, HistoryUnavailable); Next says what to use instead
  6    ask the user: StatGlass not running (AppNotRunning) or not installed (AppNotInstalled), command-line access off (AccessDisabled), StatGlass could not open its socket (AccessUnavailable), StatGlass older than this tool (AppOutdated) or it does not support the request (Unsupported)
  130  interrupted (Interrupted, Ctrl+C)

A text failure prints a fixed message, detail lines (Host:, Did you mean:) and a final Next: line on stderr. With --json, stdout is empty and the last stderr line is one envelope, {"error":{"tag","message","retryable","next","details"}} (statglass schema error). Match on tag, never on message.

Freshness: answers about a remote host carry its state, when it was last seen and how far its mirror is synced. Text prints one line when data is not current, such as "m1-linux offline since 09:12; history through 09:12". Time after the synced-through point is a not_synced gap, not a flat line.

Gaps: every span with no data is a gap with a reason: sleep, app_not_running (StatGlass was not running), paused, module_disabled (one module only), source_offline (host offline), truncated, clock_changed, write_failed, not_synced, before_retention (the whole range is older than the history StatGlass keeps; range.retained_from says where it starts), no_data (no series asked for has data and nothing recorded why, often because StatGlass was not running yet). An unfamiliar reason is still a gap. Never read a gap as zero or as "nothing happened"; say the span is unknown. history lists the gaps that apply to the series asked for, with touching gaps of one reason merged; text prints the 5 longest and one line counting the rest (--all-gaps prints every one, --json has them all).

statglass doctor (or --json) reports this tool's paths, whether StatGlass is running, whether command-line access is on, and the app's version.
